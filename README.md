# Digit Recognizer from Scratch

A from-scratch implementation of a digit classifier for the MNIST handwritten digits dataset using NumPy and basic Python tooling. The notebook covers data loading, preprocessing, model training, and evaluation.

## MNIST and dataset source

MNIST is a benchmark dataset of 70,000 grayscale images of handwritten digits (0 to 9). Each image is 28 by 28 pixels with a single label. This project uses the dataset provided by the Kaggle Digit Recognizer competition:

- https://www.kaggle.com/competitions/digit-recognizer
