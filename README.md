# Digit Recognizer from Scratch (MNIST)

A hands-on from-scratch implementation of a digit classifier for the MNIST handwritten digits dataset using NumPy and basic Python tooling. The notebook covers data loading, preprocessing, model training, and evaluation.

## MNIST Dataset and Notebook

MNIST is a benchmark dataset of 70,000 grayscale images of handwritten digits (0 to 9). <br>
The original dataset is commonly split into 60,000 training images and 10,000 test images. This project uses the dataset provided by the Kaggle Digit Recognizer competition - [Kaggle Dataset](https://www.kaggle.com/competitions/digit-recognizer)

<b>Kaggle Notebook</b>: [Digit Recognizer Notebook](https://www.kaggle.com/code/supratikbhowal/digit-recognizer-from-scratch-mnist)
